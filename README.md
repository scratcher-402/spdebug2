# spdebug2
Библиотека для логов и отладки проектов на C

## Описание
SPDebug2 - легковесная библиотека для логов и дебага. Распространяется в формате одного заголовочного файла (`spdebug.h`). 

Возможности библиотеки:
- логи с разным уровнем (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `FATAL`)
- подробная распечатка чисел, массивов, строк
- Hex Dump массивов и структур
- Макрос `$errno` для распечатки ошибок Libc

## Сборка
Для сборки заголовочного файла `spdebug.h` выполните в папке репозитория:
```bash
bash ./build.sh
```

## Предупреждение
Текущая реализация может некорректно отображать цвета на Windows. Исправление планируется в будущих версиях.

## Пример
```c
#define SPDEBUG_IMPLEMENTATION
#include "spdebug.h"

int main() {
    // Макрос для инициализации библиотеки и лог-файла.
    // Его использовать необязательно, но если использовать, 
    // то лог-файл не будет создан.
    $init;
    
    // Вывод логов с разными уровнями. 
    // Функции поддерживают форматирование вывода, как в функции printf.
    $debug("Hello World");
    int a = 2, b = 2;
    $info("%d + %d = %d", a, b, a + b);
    $warn("Some warning");
    $err("Some error");
    $fatal("Some fatal error");
    
    // Детальный вывод строк (с индексами, экранированием непечатных символов)
    const char* str = "Hello\tSPDebug2\n\xea";
    $vd(str);
    
    // Hex Dump объектов (автоматическое определление размера)
    int arr[5] = {67, 42, 52, 57, 376};
    $xdi(arr);
    
    return 0;
}
```
